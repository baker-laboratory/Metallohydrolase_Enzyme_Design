# Contributing

[← Documentation](README.md)

Read the relevant directory README and inspect `git status --short` before
editing. [AGENTS.md](../AGENTS.md) gives guidance for coding agents.

## Preserve provenance

Keep raw measurements, deposited sequences/models, theozymes, and historical
outputs intact unless changing them is part of the task. For analysis changes,
explain the affected datasets, calibration or fitting choices, and changed
results. Distinguish fresh calculations from historical figure reproductions.

Notebook runs can overwrite tracked figures. Review those diffs separately
from documentation changes. Keep submodule pins stable during unrelated work.

## Keep setup portable

Use repository-relative paths and the existing
[environment](../Scripts/env_config.py) and [ligand-tool](../Scripts/repo_paths.py)
helpers. Keep checkpoints, credentials, local environments, and container images
out of Git. Put installation commands in the [environment guide](../Environment/README.md).

Keep analysis dependencies aligned across `analysis.yml`,
`requirements-analysis.txt`, and `pixi.toml`. Preserve `zinc_hydro.lock.yml` as
the historical export; document the platform and validation of any new solve.

## Check and describe changes

- Check links, filenames, commands, and citations; run `git diff --check`.
- Run focused checks for changed code or dependencies. Some existing tests
  under [Scripts](../Scripts/) require model packages or PyRosetta.
- Do not execute whole campaign notebooks to check prose: cells can submit jobs
  or generate large outputs.
- Describe what changed, why, the validation performed, and remaining limits.

Use [GitHub Issues](https://github.com/baker-laboratory/Metallohydrolase_Enzyme_Design/issues)
for problems; include the command, traceback, commit, and environment. Keep
bibliographic updates consistent across the README, [citation guide](citations.md),
[BibTeX](references.bib), and [CITATION.cff](../CITATION.cff).

## README artwork

The README masthead, navigation plates, publication plates and pipeline
diagram in [`assets/readme/`](assets/readme/) are generated by
[`build_assets.py`](assets/readme/build_assets.py). Edit the script, not the
SVGs:

```bash
uv run --no-project --with fonttools --with uharfbuzz --with numpy \
    python -I Docs/assets/readme/build_assets.py
```

It caches its sources outside the repository. Fonts come from a pinned
`google/fonts` commit: Newsreader (© 2020 The Newsreader Project Authors) and
Mona Sans (© 2022 The Mona Sans Project Authors, Reserved Font Name "Mona"),
both under the SIL Open Font License 1.1. Coordinates are a live RCSB download
of [PDB 1QJI](https://www.rcsb.org/structure/1QJI) (Grams *et al.*,
[*Nat. Struct. Biol.* **3**, 671 (1996)](https://doi.org/10.1038/nsb0896-671)),
not a pinned file, so review the diff if a regeneration changes the geometry.
Type is converted to outlines, so the files carry no font dependency. Keep
every asset self-contained: no scripts, no `foreignObject`, no remote
references, and a `<title>` plus README `alt` text for each meaningful image.

The masthead ribbon, its active site, and the pipeline's zinc-site and sequence
panels are drawn from 1QJI, a crystal structure rather than a designed enzyme.
The pipeline as a whole is schematic: its noise cloud and overlaid traces are
seeded perturbations of the 1QJI trace, not diffusion outputs or AlphaFold
results, and its assay wells are not measurements. Keep this stated in the
pipeline's accessible label and do not substitute results without provenance.

Colours are IPD blue `#4D97B7`, pink `#B11186`, and purple `#4B2E83`, matching
the [official IPD logo](https://www.ipd.uw.edu/wp-content/uploads/2025/03/IPD-logo-UW-color-2025.png)
and the [named PyMOL colors](https://github.com/SethWoodbury/pymolrc/blob/4cfc4d9f1838696b34d0f430394fb2fda850654a/.pymolrc#L118-L124),
with deeper and lighter tints for plates and type. Ribbon colour follows facet
angle and sequence position. The plates sit on a dark ground so one asset set
reads on both GitHub themes. Keep display sizes for the
[animations](media.md) unchanged.

The README column depends on GitHub's layout, not just the viewport: it is 324 px
at a 390 px viewport, 406 px at 768 px, 570 px at 1012 px, and 838 px from
1280 px. `<picture>` sources therefore use the masthead's narrow art up to
1011 px, and the pipeline's narrow art (capped at 640 px) and 142 px navigation
plates up to 1199 px. Recheck these against the repository page if the layout
changes.
