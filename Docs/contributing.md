# Contributing

[← Documentation](README.md)

Read the relevant directory README and inspect `git status --short` before
editing. [AGENTS.md](../AGENTS.md) gives guidance for coding agents.

## Preserve provenance

Keep raw measurements, deposited sequences/models, theozymes, and historical
outputs intact unless changing them is part of the task. For analysis changes,
explain the affected datasets, calibration or fitting choices, and changed
results. Distinguish fresh calculations from historical figure reproductions.

Notebook runs can overwrite tracked figures. Review those diffs separately
from documentation changes. Keep submodule pins stable during unrelated work.

## Keep setup portable

Use repository-relative paths and the existing
[environment](../Scripts/env_config.py) and [ligand-tool](../Scripts/repo_paths.py)
helpers. Keep checkpoints, credentials, local environments, and container images
out of Git. Put installation commands in the [environment guide](../Environment/README.md).

Keep analysis dependencies aligned across `analysis.yml`,
`requirements-analysis.txt`, and `pixi.toml`. Preserve `zinc_hydro.lock.yml` as
the historical export; document the platform and validation of any new solve.

## Check and describe changes

- Check links, filenames, commands, and citations; run `git diff --check`.
- Run focused checks for changed code or dependencies. Some existing tests
  under [Scripts](../Scripts/) require model packages or PyRosetta.
- Do not execute whole campaign notebooks to check prose: cells can submit jobs
  or generate large outputs.
- Describe what changed, why, the validation performed, and remaining limits.

Use [GitHub Issues](https://github.com/baker-laboratory/Metallohydrolase_Enzyme_Design/issues)
for problems; include the command, traceback, commit, and environment. Keep
bibliographic updates consistent across the README, [citation guide](citations.md),
[BibTeX](references.bib), and [CITATION.cff](../CITATION.cff).

## README artwork

The **Computational design of metallohydrolases** masthead uses the slogan
**Hypothesis-driven enzyme design using quantum chemistry and generative deep
learning**. Its artwork, navigation
cards, publication cards and pipeline diagram in [`assets/readme/`](assets/readme/)
are generated by [`build_assets.py`](assets/readme/build_assets.py). Edit the
script, then regenerate from the repository root:

```bash
uv run --no-project --python 3.12 --with fonttools --with uharfbuzz \
    --with numpy --with biotite==2.0.0 \
    python -I Docs/assets/readme/build_assets.py
```

Mona Sans comes from a pinned `google/fonts` commit (© 2022 The Mona Sans
Project Authors, Reserved Font Name "Mona"; SIL Open Font License 1.1).
The masthead and cards use weights 400/600, aligned with
[GitHub's Primer typography](https://primer.style/product/primitives/typography/);
the pipeline retains its 450/620 weights. Type is outlined, so readers need
no fonts installed. Keep SVGs self-contained, with a `<title>` and README
`alt` text for meaningful images; avoid scripts, `foreignObject` and remote
references.

The masthead depicts the **ZAPP-1 computational design model** from the
[deposited design models](../Manuscript_Data/Phosphotriesterase_RFdiffusion3_Science_2026/supplemental_data/supp_data__denovo_PTE_design_models.zip),
identified as `ZAPP1` / `R1 p1D1` in the
[sequence workbook](../Manuscript_Data/Phosphotriesterase_RFdiffusion3_Science_2026/supplemental_data/supp_data__denovo_PTE_DNA_and_protein_sequences.xlsx)
(`all_designs`, row 38). The generator checks the model member's hash and
retains both zinc ions and the YYE ligand. Biotite's P-SEA assignment supplies
secondary structure for the cartoon only; model coordinates stay unchanged.

The pipeline remains a schematic based on the
[1QJI crystal structure](https://www.rcsb.org/structure/1QJI)
([Grams *et al.*, 1996](https://doi.org/10.1038/nsb0896-671)). The active-site icon
shows the metal and three imidazole rings, without Cβ or backbone stems. Its noise cloud,
overlaid traces and assay wells illustrate stages, not model results or
measurements. Keep this distinction in its accessible label. Fonts and the
live RCSB 1QJI download are cached outside the repository; review geometry
changes if RCSB updates that entry.

Colours are IPD blue `#4D97B7`, pink `#B11186`, and purple `#4B2E83`, matching
the [official IPD logo](https://www.ipd.uw.edu/wp-content/uploads/2025/03/IPD-logo-UW-color-2025.png)
and the [named PyMOL colors](https://github.com/SethWoodbury/pymolrc/blob/4cfc4d9f1838696b34d0f430394fb2fda850654a/.pymolrc#L118-L124),
with deeper and lighter tints for plates and type. Ribbon colour follows facet
angle and sequence position. The plates sit on a dark ground so one asset set
reads on both GitHub themes. Keep display sizes for the
[animations](media.md) unchanged.

Navigation cards are 170 × 60 px, scaling to about 142 × 50 px on narrow
screens. GitHub's sidebar changes the README column width: `<picture>` uses
the narrow masthead up to 1011 px, and the narrow pipeline (capped at 640 px)
and smaller navigation cards up to 1199 px. Recheck the repository page at
desktop, tablet and phone widths if its layout changes.
