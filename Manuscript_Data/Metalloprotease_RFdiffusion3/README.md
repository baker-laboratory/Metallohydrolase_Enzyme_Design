# Metalloprotease — RFdiffusion3

> **Status: in preparation.** This dataset is being prepared for release
> alongside RFdiffusion3, and will be published here shortly.

## Scope

Experimental characterization of de novo Zn(II) metalloproteases (amide bond hydrolysis) designed with
RFdiffusion3, in the same four-part layout used by every campaign here:

```
Metalloprotease_RFdiffusion3/
├── raw_wetlab_data/            # primary instrument output
├── supplemental_data/          # sequences, models, theozymes
├── wetlab_data_analysis.ipynb  # analysis and figures
└── wetlab_data_plots/          # generated figures
```

The matching design campaign is
[`../../Design_Pipelines/Metalloprotease_RFdiffusion3/`](../../Design_Pipelines/Metalloprotease_RFdiffusion3/).

For the published dataset in its finished form, see
[`../Metallohydrolase_Nature_2025/`](../Metallohydrolase_Nature_2025/).
